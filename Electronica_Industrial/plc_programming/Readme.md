# 💻 PLC Programming & Automation
Este directorio está dedicado exclusivamente al desarrollo de software para Autómatas Programables (PLCs). Contiene algoritmos, funciones reutilizables y arquitecturas de control diseñadas bajo estándares industriales para garantizar robustez, escalabilidad y seguridad en procesos automatizados.

## 📐 Estándar IEC 61131-3
La mayor parte del código aquí expuesto está desarrollado en Texto Estructurado (ST), permitiendo una gestión eficiente de operaciones matemáticas complejas, control de lazos (PID) y manejo de estructuras de datos pesadas que otros lenguajes visuales dificultan.

## Áreas de Aplicación:

- ***Control de Procesos***: Lazos de regulación, control de temperatura y dosificación.

- ***Máquinas de Estados***: Lógica secuencial estructurada para la gestión de modos de fallo, paradas de emergencia y ciclos automáticos.

- ***Comunicaciones***: Bloques de función para el mapeo de variables e intercambio de datos vía Modbus TCP y Profinet.
